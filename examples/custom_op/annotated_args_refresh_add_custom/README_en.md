# Ascend C Declarative Address Refresh Custom Operator Samples

This directory provides online and offline declarative address refresh samples based on `AnnotatedArgsOp::DeclareLaunchArgs`:

- [online](./online/README_en.md): Compares online execution performance between declarative address-refresh and no-refresh operators.
- [offline](./offline/README_en.md): Demonstrates AIR/OM generation, `PortableOp` serialization and deserialization, argument declaration through `DeclareLaunchArgs`, and OM loading and execution through ACL.
- [python](./python/README_en.md): Python graph construction + ATC compilation + ACL two-round NPU address-refresh validation.
