# E10410 File\_Operation\_Error\_File\_Not\_Exist

## Symptom

The following is error format. The placeholder %s indicates the file name.

```text
File %s does not exist.
```

Error example:

```text
File /home/keepdtype does not exist.
```

## Possible Cause

The file specified by the --keep\_dtype or --compress\_weight\_conf argument does not exist.

## Solution

Try again with a valid file directory.
