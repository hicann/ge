# E10059 Invalid\_Argument

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: API name, error cause.

```text
%s failed. Reason: %s.
```

Error example:

```text
SaveOriginalGraphToOmModel failed. Reason: The model file name cannot be empty.
```

## Solution

Please input correct parameter value based on the prompts in the Reason, or refer to the official documentation for parameter usage instructions.
