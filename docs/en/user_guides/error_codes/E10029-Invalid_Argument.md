# E10029 Invalid\_Argument

## Symptom

The following is error format. The placeholder %s indicates the error cause.

```text
Attribute name of Op %s is empty in the file specified by --singleop.
```

Error example:

```text
Attribute name of Op Add is empty in the file specified by --singleop.
```

## Solution

Check that the Op attribute name is not empty in the file.
