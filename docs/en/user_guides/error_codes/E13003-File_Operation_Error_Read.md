# E13003 File\_Operation\_Error\_Read

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: file name, error cause.

```text
Failed to read file %s. Reason: %s.
```

Error example:

```text
Failed to read file /home/json.json. Reason: [Error 13] Permission denied.
```

## Possible Cause

Failed to read the file.

## Solution

Please locate the issue based on the prompts in the Reason and provide the correct file.
