# E10014 Invalid\_Argument

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: parameter value, parameter name.

```text
Value %s for parameter --%s is invalid.
```

Error example:

```text
Value abc for parameter --input_shape is invalid.
```

## Solution

Run the "**atc -h**" command to view the usage. For details, see ATC Instructions.
