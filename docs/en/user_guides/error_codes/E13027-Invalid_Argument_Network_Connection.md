# E13027 Invalid\_Argument\_Network\_Connection

## Symptom

The following is error format. The placeholder %s indicates the ip address.

```text
Failed to connect to the peer address %s.
```

Error example:

```text
Failed to connect to the peer address 192.0.0.1.
```

## Possible Cause

The ipaddr, port or token is invalid.

## Solution

Check ipaddr, port or token in the configuration file, ensure that the configuration is correct.
