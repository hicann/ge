# W11001 Performance\_Not\_Optimal\_Operator

## Symptom

The following is error format. The placeholder %s indicates the op name.

```text
Op %s does not hit the high-priority operator information library, which might result in compromised performance.
```

Error example:

```text
Op add does not hit the high-priority operator information library, which might result in compromised performance.
```

## Possible Cause

The operator does not hit the high-priority operator information library, which might result in compromised performance.
