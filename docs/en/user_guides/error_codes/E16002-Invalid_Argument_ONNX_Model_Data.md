# E16002 Invalid\_Argument\_ONNX\_Model\_Data

## Symptom

The following is error format. The placeholder %s indicates the op type.

```text
No ONNX parser is registered for optype %s.
```

Error example:

```text
No ONNX parser is registered for optype CustomOp.
```

## Solution

Check the version of the installation package and reinstall the package. For details, see the installation reference.
