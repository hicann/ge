# E13001 File\_Operation\_Error\_Open

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: file path, error cause.

```text
Failed to open file %s. Reason: %s.
```

Error example:

```text
Failed to open file /home/json.json. Reason: [Error 13] Permission denied.
```

## Solution

Please locate the issue based on the prompts in the Reason and provide the correct file.
