# E10055 Not\_Supported

## Symptom

The following is error format. The placeholder %s indicates the error cause.

```text
The operation is not supported. Reason: %s.
```

Error example:

```text
The operation is not supported. Reason: Options soc_version Ascend910B and mode 0 must be set together.
```

## Solution

Check whether the configured parameter or used function is supported.
