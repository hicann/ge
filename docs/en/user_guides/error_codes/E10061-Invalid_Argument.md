# E10061 Invalid\_Argument

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: parameter value, parameter name, expected value.

```text
Value %s for parameter %s is invalid. Expected value: %s.
```

Error example:

```text
Value NZ for parameter input_format is invalid. Expected value: ND, NCHW, NHWC, CHWN, NC1HWC0, or NHWC1C0.
```

## Solution

Please input correct value based on the prompts in the error message.
