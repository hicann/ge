# E13006 File\_Operation\_Error\_Parse

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: file type, file name, expected file type.

```text
Type %s of file %s is incorrect. Expected type: %s.
```

Error example:

```text
Type 00170000 of file /home/file is incorrect. Expected type: 0100000.
```

## Solution

Please retry with valid file.
