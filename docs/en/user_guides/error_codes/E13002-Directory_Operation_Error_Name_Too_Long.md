# E13002 Directory\_Operation\_Error\_Name\_Too\_Long

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: directory, length.

```text
Directory %s is too long. Keep the length within %s characters.
```

Error example:

```text
Directory /home/demo/.../latest/test is too long. Keep the length within 4096 characters.
```

## Solution

Please retry with valid directory.
