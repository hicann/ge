# E13026 File\_Operation\_Error\_Invalid\_Path

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: file path, error cause.

```text
Input path %s is invalid. Reason: %s
```

Error example:

```text
Input path /home/file is invalid. Reason: It is not a real path. Please check your model path.
```

## Solution

Please provide valid file path based on the prompts in the Reason
