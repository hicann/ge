# E10017 Invalid\_Argument

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: op name, parameter name.

```text
Input Op %s specified in --%s is invalid. The Op type must be Data.
```

Error example:

```text
Input Op input1 specified in --input_shape is invalid. The Op type must be Data.
```

## Solution

Please input correct value based on the prompts in the error message.
