# E10057 Invalid\_Argument

## Symptom

The following is error format. The placeholders %s indicate the parameter name.

```text
--%s and --%s can only be used together.
```

Error example:

```text
--om and --model can only be used together.
```

## Solution

If the value of --mode is 6, it only needs to be used with --om. Please check and try again.
