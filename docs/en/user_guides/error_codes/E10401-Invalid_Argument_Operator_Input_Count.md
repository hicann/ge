# E10401 Invalid\_Argument\_Operator\_Input\_Count

## Symptom

The following is error format. The meanings of the placeholders %s in sequence are: input number, maximum number.

```text
The number of operator inputs %s exceeds the allowed maximum %s.
```

Error example:

```text
The number of operator inputs 5 exceeds the allowed maximum 4.
```

## Solution

Try again with a valid number of inputs.
