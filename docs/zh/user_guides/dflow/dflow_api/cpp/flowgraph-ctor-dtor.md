## 函数功能

FlowGraph构造函数和析构函数，构造函数会返回一张空的FlowGraph图。

## 函数原型

```cpp
FlowGraph(const char *name)
~FlowGraph()
```

## 参数说明

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| name | 输入 | FlowGraph的名称。 |

## 返回值

返回一张空的FlowGraph图。

## 异常处理

无。
